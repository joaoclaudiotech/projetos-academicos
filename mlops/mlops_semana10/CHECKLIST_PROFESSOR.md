# Checklist pré-aula do professor

- Abra o HTML do professor e navegue pelas 15 telas.
- Confirme internet no laboratório para o primeiro `pip install -r requirements.txt`.
- Se puder, instale BentoML antes da aula em pelo menos uma máquina.
- A prática principal NÃO depende de Docker.
- O código foi atualizado para BentoML 1.4.39: `@bentoml.service` / `@bentoml.api`.
- O aluno deve entregar PDF com prints e explicações, não apenas código.
